## Name
materia-source-local - Configuration for Materia Local Repository Source

## Synopsis

`/etc/materia/config.toml, $MATERIA_FILE__*`

## Description

Configures a local directory as a the source for the Materia repository


### Options

#### `MATERIA_LOCAL__SOURCE_PATH`/ **local.source_path**

Path for the local repository

#### `MATERIA_LOCAL__DESTINATION`/ **local.destination**

Manual override for source repository destination
